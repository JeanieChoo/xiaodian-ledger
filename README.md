# Roccopet 小店合记

进货、销售、库存、退货运费、AA 结算和 Excel 订单导入。

## 使用方式

使用完整的专属共享链接打开，即可进入同一本云端账本。无需注册、验证码或口令。进入后可以点击“复制共享链接”发给合伙人。共享链接本身是访问凭证，不能公开发布。

网站由 GitHub Pages 托管。账目和截图保存在 Supabase 私有数据库中，公共 API 密钥不能单独读取账本。服务器逐笔校验旧版本，防止设备之间覆盖修改；导入标识唯一约束防止重复记账。删除记录在数据库中保留恢复信息。

页面每隔约 6 秒读取云端变化；编辑窗口打开时暂缓刷新，避免打断填写。保存成功后才提示已同步，断网会明确提示失败。

## 本机演示数据

新云端账本不自动混入本机演示记录。旧浏览器本机数据保留在原地址。原订单文件可在云端账本重新导入，后续重复导入会自动查重。

## 源码与隐私

此仓库只包含网站程序和公开连接配置。专属链接凭证、数据库密码、订单表、顾客信息和截图不提交到仓库。

Excel 解析使用 SheetJS CE，许可见 LICENSE-SheetJS.txt。
