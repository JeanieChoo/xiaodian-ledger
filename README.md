# 小店合记

进货、销售、推广、退货运费、库存、AA 结算与订单表导入。

## 当前交付状态

此目录是清理后的静态网站发布包，不包含用户订单表、顾客资料或截图。当前版本的数据保存在各自浏览器中；云端同步尚未接通。发布网页并不等于开通共享账本。

## GitHub Pages

将本目录内容上传到仓库根目录。在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存。等待 GitHub 显示发布成功后使用其返回的网址。

## 两人共享版本的接入要求

- Supabase Auth：两人各自使用邮箱登录。
- 同一本账的成员表控制访问；数据库启用 RLS，未加入账本的用户不可读取或修改。
- 每笔账、资金往来按记录保存，带版本号。更新时校验版本；冲突时提示重新读取，不覆盖别人的修改。
- 同一账本内对导入标识建立唯一约束；导入批次由数据库事务完成，避免两人同时导入产生重复。
- 截图存入私有 Storage bucket，按账本成员授权读取，禁止公共截图链接。
- 同步失败必须显示失败状态；不能把本机保存说成云端已同步。
- 原浏览器数据先导出备份，再通过明确的迁移操作导入云端，不能自动把演示数据上传。

只允许前端使用公开的项目 URL 和 publishable key；数据库密码、service_role key、访问令牌不得提交到仓库。
